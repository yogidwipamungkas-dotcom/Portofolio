# Portfolio Yogi Dwi Pamungkas

## Menjalankan website
1. Ekstrak folder `yogi-portfolio`.
2. Buka folder di VS Code.
3. Buka `index.html` dengan Live Server.

## Personalisasi yang perlu dilakukan
- Ganti blok `.portrait-placeholder` di `index.html` dengan foto profesional, misalnya:
  `<img class="portrait-photo" src="assets/foto-yogi.jpg" alt="Yogi Dwi Pamungkas">`
  lalu tambahkan aturan CSS untuk `.portrait-photo` agar memenuhi area foto.
- Letakkan file CV bernama `CV-Yogi-Dwi-Pamungkas.pdf` di folder `assets/`.
- Simpan foto dokumentasi dan sertifikat di `assets/evidence/`.
- Untuk menampilkan foto pada kartu bukti, ubah tombol `.evidence-card` terkait: tambahkan class `has-image`, isi `data-image="assets/evidence/nama-file.jpg"`, dan sesuaikan deskripsi.
- Jangan unggah dokumen audit yang berisi data rahasia, data klien, informasi pribadi pihak lain, atau informasi internal instansi. Gunakan foto yang sudah mendapat izin dan sertifikat yang aman dipublikasikan.

## Catatan
Konten pengalaman dan pendidikan disusun berdasarkan CV yang diberikan. Periode "21 September–Sekarang" ditampilkan mengikuti CV; perbarui tanggal jika sudah berubah.
